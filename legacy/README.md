# legacy

`mac-24.04.sh` — первый монолитный скрипт для **Ubuntu 24.04 (GNOME 46)**: WhiteSur, oh-my-zsh + Powerlevel10k, Nerd Fonts, Blur My Shell из исходников. Не поддерживается, для 26.04 используйте `install.sh`.

> ⚠️ Скрипт удаляет **весь** `~/.themes` и `~/.icons` (не только WhiteSur), а резервная копия создаётся в каталоге с буквальным именем `~` из-за кавычек в `BACKUP_DIR`. Перед запуском сохраните эти каталоги вручную.
